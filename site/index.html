FieldBench

CAN / ISOBUS test bench for precision-farming systems

Simulated tractor and guidance ECUs on a virtual CAN bus. Test procedures come from a YAML system spec and run with pytest: cycle times, timeouts, signal ranges and fault injection. Failures become tracked issues with log excerpts.
